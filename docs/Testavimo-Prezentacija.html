04 / 17
Apribojimai

Teisiniai, techniniai ir valdymo apribojimai

⚖️ Teisiniai / norminiai
BDAR/GDPR Studentų pažymiai = asmens duomenys. BCrypt + JWT + prieigos kontrolė privaloma.
OWASP Top 10 Privaloma tikrinti A01–A07 pažeidžiamumus.
Akademiniai Dokumentuojami visi etapai pagal kurso reikalavimus.
🔧 Techniniai
  • EF Core InMemory – nenaudoja realios SQL semantikos; UNIQUE ribojimų netikrina DB lygyje
  • JWT raktas env kintamajame – docker-compose.yml eksponuoja jei nesaugioje vietoje
  • SQL Server Express – max 10 GB, nėra HA/failover – netinka produkcijai
  • nginx – nėra HTTPS – P1 defektas, kritinis apribojimas produkcijai
  • Nėra CI/CD – testai nevykdomi automatiškai kiekvienam commit
🗂️ Projekto valdymo
  • Riboti ištekliai – studentų komanda; prioritizuojami kritiniai testai
  • Akademiniai terminai – testavimas vykdomas lygiagrečiai su kūrimu
  • Nėra QA aplinkos – testavimas tik lokaliose Docker aplinkose
  • Kokybės standartai – ISO/IEC 25010, ISTQB geriausios praktikos
Darbų apimtys
Iš viso suplanuota 95 testų atvejų
Įvykdyta ~79 · Praeina ~78 · Nepavyko ~1

// Arrange
var options = TestDbContextFactory.Create();
using var ctx = new AppDbContext(options);
ctx.Students.Add(new Student { ... });
// Act

// Assert
Assert.IsType<OkObjectResult>(result);
