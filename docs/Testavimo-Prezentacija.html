Produkto kontekstas

StudentPortal – komercinė švietimo valdymo sistema (EMS), teikiama kaip SaaS sprendimas švietimo įstaigoms. Defektai produkcijoje tiesiogiai veikia SLA ir BDAR atitiktį.

  • Vienetų testai parašyti ir praeina
  • Padengimas ≥ 80% naujam kodui
  • PR peržiūrėtas ir patvirtintas (Senior/Mid)
  • CI pipeline praeina (build + testai)
  • 0 P1 defektų atviri
  • Manualinis TC įvykdytas (jei reikia)

Problemos ir rizikingos vietos

Aptiktos problemos, sprendimai ir techninė skola

Problemos ir sprendimai

1. ESM moduliai nesuderinami su Jest

Problema: axios + jwt-decode naudoja ES Modules – Jest blokuojamas (SyntaxError)
Sprendimas: transformIgnorePatterns konfigūracija package.json
Poveikis: CI blokuotas ~2 val. | Mid Dev

2. Bendras padengimas 10.3% – klaidinga interpretacija

Priežastis: EF Core Migrations/ sudaro ~80% kodo eilučių
Sprendimas: Paaiškinimas ataskaitoje + Coverlet exclude konfigūracija
Senior Dev | P3

3. InMemory DB nesimuliu SQL taisyklių

Priežastis: UNIQUE/FK neveikia InMemory – validacija perkelta į kodą
Planas: TestContainers (SQL Server Docker) | Sprint 5

4. Sudėtingi komponentai – žemas padengimas

Priežastis: StudentPage, TeacherPage – daug priklausomybių (AuthContext, Router, API)
Planas: Refaktoruoti į custom hooks + renderHook | Sprint 5
